Entry for the [What the Elevator Would Say](https://make.fun/bounty/u-eager-stork-81-9647-what-the-elevator-would-say-90844958) bounty on make.fun: the funniest one line a talking elevator could say, in the elevator's own voice, at most 120 characters.

`main.py` (Python 3.13, stdlib only) writes that one line to `<output dir>/entry.txt`, reading the output directory from `OUTPUT_DIR` when set, otherwise `/output`.

## Run

```sh
OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
